Bill Management System is a python based application which helps to make the bill creation process easier.

The user can enter customer details and product details and can calculate the amount with the help of the application.

The system will also add the GST to the total amount and then finally create a bill with the total amount including the GST.

The application is developed with the help of Python, TkInter and SQLite.
Features

- Customer details
- Product Entry
- Calculate Bill
- Subtotal calculation
- Calculating GST
- Final Bill Calculation
- Creating Bill
- Bill History
- Database using SQLite
- Billing Analytics
- GUI based application

Requirements
The application needs python 3 or higher version to run.
The application uses the inbuilt python libraries only, there is no need to install any external packages.
Installation
Open the project in the VS code.
Open the terminal and type
python main.py
If the above command is not working type
py main.py
How to Use
1. Launch the Application
2. Enter the Customer's details
3. Enter the Product name
4. Enter the Quantity of the Product
5. Enter the Price of the Product
6. Add product to the bill
7. Add more products if needed
8. Calculate subtotal
9. Calculate GST
10. Generate Final Bill
11. Save Bill
12. View History
